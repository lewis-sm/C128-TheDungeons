**The Dungeons** was one of the earliest computer games I ever played on the Commodore 64 back in the 1980's. I may have played the earlier version on the Commodore VIC-20 as well at some point; as I played a lot of Dungeons & Dragons back then so the game really appealed to the younger me.

The source code in this repository is a C128 version of the game based on a deconstructed C64 version I created which is available in the reposirory: https://github.com/lewis-sm/C64-TheDungeons

I plan to create a 'reloaded' version of the game next, digging into the capabilities of the richer C128 platform and BASIC v7 to (re)learn some of those earlier programming experiences.  I'm not sure I really ever delved very far in BASIC v7 as I was beginning to transition into other business languages around this time, so I sort of skipped over the opportunity.

The game also now has a save and load game option to disk, instead of the original option which was designed to save to tape, for convenience.  

Disclaimer:  I have used AI (Claude and Co-pilot) to help with some of the tricker pieces of getting this fully working, but the core BASIC game code and assets all remain untouched from the earlier C64 version.
